## Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas**, direcionando minha carreira para **Análise de Dados**.

Meu foco é transformar perguntas de negócio em análises reproduzíveis: exploro e trato dados, escrevo consultas SQL, crio visualizações e apresento insights de forma objetiva. Também uso automação para reduzir tarefas manuais e melhorar a qualidade do trabalho analítico.
